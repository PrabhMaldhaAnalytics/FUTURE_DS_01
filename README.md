# Sales-Data-Analysis
Power BI Sales Dashboard analyzing total sales, profit, orders, and regional performance – Internship Task 1 with Future Interns.
🚀 Task 1 – Sales Performance Dashboard
Internship with Future Interns

This project was completed as Task 1 during my internship with Future Interns.

📊 Project Overview

The objective was to create a clean and interactive Sales Dashboard using the Sample Superstore dataset in Power BI.

🔍 Key Metrics Included:

Total Sales: 2M+

Total Profit: 286K+

Total Orders: 5009

Profit Margin: 12.5%

Monthly Sales Trend

Sales by Category

Sales & Profit by Region

🛠 Tools Used:

Power BI

DAX (DISTINCTCOUNT, Profit calculations)

Data Modeling

📈 Key Insights:

West region generated highest profit

Technology category contributed highest sales

Sales peak observed in November

This dashboard focuses on clear layout design, KPI structuring, and business storytelling.
